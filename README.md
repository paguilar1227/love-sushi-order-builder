# Love Sushi Order Builder

A single-file HTML app to browse the Love Sushi menu, build an order, calculate totals (tax + tip), and save/export orders.

## Live demo

https://cdn.jsdelivr.net/gh/paguilar1227/love-sushi-order-builder@main/index.html

## Source

Menu data from menu.pdf (Sep 2024).

## Features

- Search and category tabs
- Item options (e.g. sushi vs sashimi, add-ons, roll choices)
- Cart with quantity controls
- Tax rate (default 8.25%)
- Tip / party gratuity (18% for 6+)
- Save named orders locally
- Export/import JSON
